# Anatomía en capas (Layered Human Anatomy)

🇪🇸 [Versión en español](README.es.md)

Interactive 3D atlas of the human body for educational use. It includes 934 anatomical structures in 11 systems, with layers you can toggle, per-system opacity, search, and a description card for each structure. **The interface and the cards are in Spanish.**

**Try it online:** https://anatomia.alexisparron.com (the deployed version adds the site's analytics; the code in this repository contains no trackers).

## Usage

1. Clone the repository, or download it as a zip and unpack it.
2. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari).

It works offline and needs no installation. Fonts are bundled in `fonts/` (Newsreader and IBM Plex, SIL OFL 1.1), so no external server is contacted.

To modify the viewer, edit `src/visor.js` and regenerate `app.js`:

```
npm ci
npm run build
```

To publish it on the web, upload the folder as is to any static host (GitHub Pages, Netlify, Vercel…).

## Data source and credits

The 3D meshes derive from **BodyParts3D**, © The Database Center for Life Science (DBCLS), Japan, distributed under [CC BY-SA 2.1 Japan](https://creativecommons.org/licenses/by-sa/2.1/jp/).
Source: https://lifesciencedb.jp/bp3d/ (copy used: https://github.com/Kevin-Mattheus-Moerman/BodyParts3D).

**Changes made to the original meshes:** simplification from about 26 million to 3.3 million triangles; axis and unit change (mm to m); meshoptimizer compression; color assignment and grouping by system.

The Spanish description cards are original work of this project.

## Limitations

Single adult male model. It does not include the spinal cord, peripheral nerves, thyroid gland, tongue, larynx (except thyroid cartilage), lymphatic vessels, or most limb vessels. **For educational use, not clinical.** The cards have not been reviewed by specialists; a teacher should review them before classroom use.
