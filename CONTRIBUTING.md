# Contribuir / Contributing

*Español primero, English below.*

## Español

¡Gracias por querer ayudar! Las aportaciones más útiles son:

- **Correcciones de fichas anatómicas** (`data/anatomia.js`, y los scripts `herramientas/anat_a.py`, `anat_b.py`, `anat_c.py`, que son su origen). Indica la fuente (atlas, terminología anatómica) en el issue o en la PR. Las fichas no han sido revisadas por especialistas, así que la revisión por docentes y profesionales es especialmente valiosa.
- **Errores del visor** (`src/visor.js`, `index.html`).
- **Mejoras de accesibilidad, rendimiento o traducciones** (ver «Añadir un idioma» más abajo).

### Entorno de desarrollo

```
npm ci
npm run build   # regenera app.js desde src/visor.js
```

Abre `index.html` en el navegador. **No edites `app.js` a mano**: es un fichero generado; incluye el resultado del build en tu PR.

Los ficheros `models/*.js` y `data/anatomia.js` se generan con los scripts de `herramientas/` (ver `herramientas/LEEME.md`); si cambias la lógica de datos, cambia el script y regenera.

### Añadir un idioma

La interfaz y las fichas se separan por idioma. El español es el texto base (`data/anatomia.js`); cada idioma extra es una capa:

1. En `src/i18n.js`, añade el código a `LANGS` y `LANG_NAMES` y copia el bloque `en` de `STR` con tus traducciones (lo que falte se toma del español). Regenera con `npm run build`.
2. Crea `data/anatomia.<código>.js` con el mismo formato que `data/anatomia.en.js`: `window.ANAT_I18N.<código> = {systems: {clave: {n, d}}, concepts: [[nombre, grupo, descripción, [[campo, valor], …]], …]}`. El orden de `concepts` es el de `data/anatomia.js`, y los campos `[campo, valor]` deben tener el mismo número que el original. Si falta un concepto, se muestra en español.
3. Comprueba en el navegador con `index.html?lang=<código>`.

Marca como «sin revisar por especialistas» las traducciones que no lo hayan sido.

### Pull requests

1. Abre antes un issue si el cambio es grande.
2. Una PR por tema, con una descripción clara de qué cambia y por qué.
3. Comprueba que el visor carga y que no hay errores en la consola del navegador.

## English

Thanks for helping! Most useful contributions: corrections to the anatomical cards (`data/anatomia.js`, generated from `herramientas/anat_*.py`; please cite your source), viewer bugs (`src/visor.js`, `index.html`), and accessibility, performance or translation improvements. The cards have not been reviewed by specialists, so expert review is especially welcome.

**Setup:** `npm ci && npm run build` regenerates `app.js` from `src/visor.js`. Do not edit `app.js` by hand; include the rebuilt file in your PR. `models/*.js` and `data/anatomia.js` are generated by the scripts in `herramientas/`.

**Adding a language:** add the code to `LANGS`/`LANG_NAMES` and an `STR` block in `src/i18n.js`, then create `data/anatomia.<code>.js` following `data/anatomia.en.js` (same order as `concepts`; missing entries fall back to Spanish). Test with `index.html?lang=<code>`.

**Pull requests:** open an issue first for big changes, keep one topic per PR, and check that the viewer loads without console errors.

**Licensing of contributions:** by contributing you agree your work is published under the license of the file you modify: **MIT** for code, **CC BY-SA 4.0** for meshes and cards. Do not include third-party material that is incompatible with CC BY-SA.

Please follow the [code of conduct](CODE_OF_CONDUCT.md).
